**Group CEO sẽ thực hiện:**
1. Phân tích bài toán hiệp lực (Synergy) giữa mảng Digital và Kế toán.
2. Tạo file `DIRECTIVE_Q4.md` tại `D:\project antigravity\Agency Agent` giao việc cho Giám đốc Digital.
3. Tạo file `CROSS_SELL_OFFER.md` tại `D:\project antigravity\Project\ke toan` giao việc cho Giám đốc Kế toán.
4. Trình bản tổng hợp điều hành lên Chủ tịch phê duyệt.
